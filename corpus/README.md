# Performance Modeling, Profiling & Tuning Corpus Mirrors

This directory contains isolated validation mirrors for four MindIE domain knowledge corpora. Each subdirectory stages graded knowledge units (`schema: mindie-graded-unit/1`) covering Ascend NPU performance modeling, steady-state profiling, operator ABI reproduction, and ablation-gated graph tuning prior to upstream corpus publication.

| Domain Mirror | Units | Coverage |
| --- | --- | --- |
| `knowledge-vllm-ascend/` | 4 | Per-rank HBM ownership ledger, launch-to-SOL modeling, seven-arm MLAPO ablation protocol, and Day-0 MLAPO mutator |
| `knowledge-operators/` | 2 | ACLGraph bucket-padding and varlen contracts, named operator ABI binding, and standalone single-op reproduction |
| `knowledge-infer-distributed/` | 1 | Joint DP/TP/EP/PCP/DCP feasibility, EP straggler knee, EPLB placement, MTP batch crossover, and xPyD pool sizing |
| `knowledge-infer-observability/` | 2 | CANN 9 steady-state capture gate (`SteadyStateGate`) and signed four-way `diff-trace` gap attribution |

Every unit is parsed and validated by `mindie_knowledge.graded` (`GradedUnit` and `RoutingIndex`), and each domain mirror maintains its own `index/routing-manifest.json` and `index/shard-topology.json` generated by `build_routing_index`.

## Verification

```bash
python3 -B -m pytest -q tests/test_modeling_knowledge_units.py tests/test_modeling_knowledge_delivery.py
```

The overlay test suite copies each production domain corpus into an isolated temporary directory when available locally, overlays these units, rebuilds `index/`, and verifies `query`, `explain`, `explore`, negative-condition filtering, and `<= 3,000`-token outward delivery budgets without mutating any checkout on disk.
