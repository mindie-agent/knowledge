# mindie-knowledge 0.13.15：企业网络配置贯通

[English](knowledge-0.13.15.en.md)

修复知识同步、社区 Git 操作和发布校验重置 `GIT_CONFIG_COUNT`、丢弃调用方代理或 CA/TLS 配置的问题。自有 Git 参数追加在原配置之后，Windows `core.longpaths=true` 继续通过进程环境启用，不修改用户或全局 Git 配置。

后台服务上下文使用 diagnostics 的共享传输配置投影，仅持久传递 Git HTTP 代理、CA 与 TLS 设置，排除凭据助手和认证头。应用新上下文时先清除上一次管理的网络变量，确保撤销代理能够生效；单次凭据仍沿用现有加密与一次消费协议。

锁定正式 diagnostics 0.5.10，包含本地 Windows 扩展路径、SQLite URI、保留清理预算、短路径诊断运行时和存活降级 worker 升级修复。现有社区授权、任务租约、队列及不确定外部写回执继续保留，不自动重放发布。

验证覆盖真实 Git 配置读取、进程边界服务环境传递、代理撤销和长路径。正式发布继续附带精确源码 benchmark、发行资产与旧客户端升级证据。现场 TCP 超时的具体网络原因仍需在发生故障的企业网络中核验。
