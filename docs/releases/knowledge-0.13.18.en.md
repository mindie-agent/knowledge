# mindie-knowledge 0.13.18: Windows CP936 / User-Scoped Git & WSL2 Non-systemd Service Hardening

[中文](knowledge-0.13.18.md)

- **WSL2 Native Binary Lookup & PE/DrvFS Shadow Exclusion (`_host_exec.py`, `gitbin.py`, `release_http.py`, `component_runtime.py`, `loop/process.py`)**: Resolves symlinks strictly (`os.path.realpath(..., strict=True)` without pre-collapsing `..` segments) before checking `/proc/self/mountinfo` (`drvfs`/`9p`) and 4 KiB PE headers so Windows `/mnt/c/.../*.exe` entries appended on WSL2 `$PATH` never shadow native Linux `git`, `gh`, `uv`, or `ps`; adds `%LOCALAPPDATA%\Programs\Git\{cmd,bin}\git.exe` discovery for user-scoped Git for Windows.
- **Linux/WSL2 Non-`systemd` User Bus Service Hosting Without Launch-Receipt Bypass (`loop/service_host.py`, `loop/systemd_service.py`, `loop/cli.py`, `loop/lifecycle.py`)**: Cleanly selects direct detached service ownership (`spawn_service` + `consumer.lock` + `posix_owner`) on Linux/WSL2 environments without a live `systemd` user bus when no `.systemd-service/launch.json` exists, forwards verified `/run/user/<uid>` `XDG_RUNTIME_DIR` to native `systemctl`/`busctl`/`systemd-run` when stripped from ambient env, and never bypasses an existing `.systemd-service/launch.json` receipt.
- **Windows `CP936` UTF-8 Discipline & `TimeoutError` Propagation**: Passes `-X utf8` to isolated `-I` Python inventory subprocesses, adds explicit `encoding="utf-8"` and `except TimeoutError: raise` guards before `except OSError:`, and upgrades `mindie-diagnostics` to formal release `v0.5.12` (`3d82313bb4b826bf52d5ec1dd64ef6476a070b4b`).
