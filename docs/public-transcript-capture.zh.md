# 公开对话材料与增量索引

中文 | [English](public-transcript-capture.md) · [返回文档索引](README.md)

本文说明 `mindie-knowledge` 如何从已验证归属的宿主原生 Transcript 中提取公开对话材料、执行隐私脱敏并完成增量分块索引。

## 1. 确定性公开消息筛选

- 仅读取当前任务明确命名的原生 Transcript，绝不扫描历史会话目录或猜测相邻会话。
- 投影规则仅保留用户输入、助手公开进展说明与最终答复；工具调用入参/结果、内部推理链（Reasoning）、系统注入指令及重复包装事件均被确定性剔除。
- 机械投影不调用模型，不对长消息做首尾截断或摘要替换。

## 2. 不可变分块与双层脱敏

- 在落盘与索引前，所有文本块必须通过固定版本 Gitleaks 与 `mindie_knowledge.redact` 规则检查。
- 脱敏后的公开对话保存为有序且不可变的 `mindie-material-block/1` 分块文件（`materials/0001.md`、`0002.md` 等），分块正文字节与其 SHA-256 标识严格绑定。

## 3. 增量导航索引与故障恢复

- 宿主原生小模型每次仅处理有界的新增分块，结合已有任务导航生成新分块的标题、摘要并更新 `PACKAGE.md`。
- 模型返回结果与 Token 用量在本地应用前先行持久化；若本地写入中断，恢复流程直接复用已保存的模型输出，绝不重复发起计费调用。
- 若小模型调用失败或结果未知，已落盘的脱敏分块保持完整，状态明确报告为索引未完成，不以原始摘录冒充已完成索引的知识包。
