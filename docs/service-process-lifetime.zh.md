# 服务与单次操作生命周期

中文 | [English](service-process-lifetime.md) · [返回文档索引](README.md)

本文规定后台知识服务、单次模型整理尝试与前台调用等待窗口之间的生命周期边界。

## 1. 寿命解耦原则

- **前台调用窗口**：MCP 请求或 CLI 命令的等待时间仅代表调用方愿意在前台等待多久，超时返回原操作身份与当前阶段，绝不等于后台操作失败或需要重新提交。
- **后台知识服务**：作为独立进程所有者运行，不随短生命周期的 Hook 启动器退出而误杀。
- **单次模型整理操作**：不设武断的业务总执行时限；只要子进程句柄存活、管道未断开且宿主未发起取消，长任务可持续分段推进直至完成。

## 2. 精确归属与安全退役

- 服务通过完整配置指纹、认证本地回环端点、启动锁与消费锁确立唯一所有权。
- 退役记录阻止迟到的唤醒请求重启已退役的旧服务，且在业务忙或状态 `unknown` 时禁止强制清理。
