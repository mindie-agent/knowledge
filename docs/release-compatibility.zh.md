# 版本准入与已安装操作锁

中文 | [English](release-compatibility.md) · [返回文档索引](README.md)

本文定义 `mindie-knowledge` 与宿主插件之间的版本兼容准入、单一安装绑定以及共享/排他操作锁机制。

## 1. 组合身份与格式校验

- 每个插件发行版通过 `product-contract.json` 与 `uv.lock` 固定唯一的 `mindie-knowledge` 版本与提交。
- 运行时启动与服务唤醒时核对完整配置指纹（解释器路径、包版本、存储 Schema 版本与宿主适配配置），拒绝跨版本混用私有内部接口。

## 2. 共享业务锁与排他切换锁

- 日常检索、状态查询、Stop 准入与后台索引持有共享锁或按序消费锁，支持正常并发与取消。
- 插件静默升级在锁外完成新环境准备后，仅在确认当前知识服务无在途采集与摘要任务时获取排他锁，精确退役旧服务并原子切换安装绑定。
- 短 Stop Hook 直接写入持久化 SQLite 准入队列，不等待升级切换锁，确保回合结束时的经验增量绝不因后台升级而丢失。
