# 显式历史会话导入

中文 | [English](history-import.md) · [返回文档索引](README.md)

本文定义显式历史 Transcript 导入契约（`import-history`）。

## 1. 适用边界与显式指定

- 日常运行仅采集当前已绑定且处于有效授权窗口内的活跃任务，绝不自动扫描或回放历史会话。
- 当用户希望将过往有价值的原生会话纳入知识闭环时，可通过显式导入接口指定具体的历史 Transcript 文件与所属项目标识。

## 2. 管线复用与安全门禁

- 显式历史导入完整复用实时采集的确定性投影、Gitleaks + `mindie_knowledge.redact` 脱敏、不可变分块落盘、原生小模型增量导航索引以及 `mindie-material-task/1` 打包协议。
- 导入操作同样检查当前用户的贡献授权与项目范围配置：未启用贡献或项目范围不匹配时拒绝导入，不绕过任何隐私与授权边界。
- 同一历史会话重复导入具有幂等性，已提交的分块与未知外部状态（`unknown`）均受账本保护。
